# Research Objectives

## Primary objective

**RO-01:** Quantify the relationship between traffic-state representation richness, observation reliability, and adaptive signal-control performance.

## Supporting objectives

- **RO-02:** Define reproducible R1–R4 traffic-state representations.
- **RO-03:** Build a controlled observation-degradation framework.
- **RO-04:** Evaluate missing observations.
- **RO-05:** Evaluate measurement noise.
- **RO-06:** Evaluate vehicle-type misclassification.
- **RO-07:** Evaluate partial observation-channel failure.
- **RO-08:** Compare fixed-time, actuated, standard RL, and reliability-aware control.
- **RO-09:** Evaluate pedestrian safety/timeliness and emergency response under degraded observations.
- **RO-10:** Quantify Information Benefit and Degradation Ratio using matched experimental conditions.
- **RO-11:** Test whether explicit observation-quality information improves robustness.
- **RO-12:** Validate the realism of observation assumptions using camera-derived traffic states.
- **RO-13:** Maintain reproducibility through fixed seeds, documented configurations, and controlled experiment matrices.
- **RO-14:** Perform ablations separating the value of richer state information from the value of explicit reliability information.
- **RO-15:** Identify failure regimes where richer information becomes neutral or harmful.
